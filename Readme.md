# Student Information System (JavaFX)

## Обзор проекта
Данный проект представляет собой ** приложение на JavaFX** для управления списком студентов с **системой авторизации**.  
После успешного входа пользователь может **добавлять, редактировать, удалять и искать студентов** в таблице.

Все изменения данных **сохраняются автоматически** в файлы JSON и CSV, поэтому отдельная кнопка сохранения не требуется.

---

## Основные возможности
- Авторизация пользователей
- Добавление студентов
- Редактирование данных студента
- Удаление студентов
- Поиск студентов по ID, имени и фамилии
- Автоматическое сохранение данных
- Загрузка данных при запуске приложения

## Проектные решения
- **JavaFX + FXML** используются для разделения пользовательского интерфейса и логики приложения.
- Архитектура проекта соответствует **MVC-подходу**:
    - `model`: `Student`, `User`
    - `controller`: `LoginController`, `HelloController`
- Для хранения данных используется **JSON** (библиотека Jackson).
- **CSV-файл** применяется как дополнительный формат хранения.
- **MD5-хеширование** используется для хранения паролей пользователей.
- Автосохранение данных выполняется при добавлении, редактировании и удалении студентов.

---

## Используемые алгоритмы и структуры данных
### Структуры данных
- `ObservableList<Student>` — основное хранилище студентов в памяти
- `FilteredList<Student>` — фильтрация студентов при поиске
- `List<User>` — список пользователей для авторизации

### Алгоритмы
- Линейный поиск пользователя при входе в систему
- Фильтрация данных с использованием предикатов
- Проверка корректности пользовательского ввода
- Хеширование паролей с использованием MD5
- Запись и чтение данных из JSON и CSV файлов

---

## Ввод и вывод данных
### Входные файлы
- `user.json` — содержит логины и хеши паролей пользователей
- `data.json` — хранит список студентов
- `filename.txt` — CSV-файл со студентами

### Выходные файлы
- Обновлённый файл `data.json`
- Обновлённый файл `filename.txt`

### Особенности
- Данные загружаются при запуске приложения
- Любые изменения сохраняются автоматически
- Потеря данных при закрытии программы исключена

## Запуск проекта
1. Открыть проект в IntelliJ IDEA
2. Убедиться, что подключены JavaFX и библиотека Jackson
3. Запустить класс `HelloApplication`
4. Выполнить вход, используя данные из файла `user.json`
